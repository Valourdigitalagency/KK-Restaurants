# KK Restaurant Website

Static restaurant ordering website customized for **KK Restaurant** with a maroon visual theme and KK Restaurant logo.

## Run locally
Open `index.html` in a browser, or serve the folder with any static web server.

## GitHub Pages
1. Create a GitHub repository.
2. Upload all files and folders in this directory.
3. In **Settings → Pages**, choose **Deploy from a branch**.
4. Select the `main` branch and `/ (root)`.
5. Save and open the GitHub Pages URL.

No build step is required.
